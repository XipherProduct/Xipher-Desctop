# НОЧЬ-2 — ДИЗАЙН-РЕВОЛЮЦИЯ: Telegram × Discord × Xipher

**Дата:** ночь 05→06.10.2026. **Вердикт юзера по волне ТЗ:** «фичи есть, дизайн — говно:
нету Телеграм + дискорд + ксифер». Функциональная волна закрыта (64/66), теперь продукт
должен ВЫГЛЯДЕТЬ как продукт, а не прототип с инлайн-стилями.

**Эталон сплава (решение по каждому источнику):**
- **Xipher (основа):** токены `web/css/tokens.css` — матовый монохром, фиолет #8B5CF6,
  hairline-границы без свечений, радиусы 8/12/16/20/24/pill, Inter, баббл-out градиент.
  Это публичный дизайн-язык (app-redesign.css), НЕ персональный слой юзера.
- **Telegram (паттерны чистоты):** плотный список чатов с активной строкой, группировка
  серий сообщений, хвостик-клюв пузыря, время в пузыре, дата-капсула, композер-пилюля,
  тонкие скроллбары, tooltips на всех иконках.
- **Discord (структура):** рейл навигации, канальные секции, info-панель справа,
  реакции-чипы-pill, переключатели-тумблеры, hover-состояния на всём.

**Запрещено:** копировать личный telegram-desktop.css юзера буквально (он «под себя»);
неоновые тени; разнобой бейджей/радиусов/цветов вне токенов.

---

## Диагноз «до» (скрин design-main.png + разбор)

1. Нет выделения активного чата в списке, нет hover-состояний строк.
2. Бейджи несогласованные: круг vs квадрат, разные размеры.
3. Спойлер — чёрный блок-артефакт (выглядит как баг рендера).
4. Сообщения — «плиты» без группировки серий: аватар на каждом, «11:55 vs 23:55»
   вразнобой, нет хвостиков, время-стили разнобой.
5. Три иконки поиска в шапке чата (дубль), «часы»-иконка непонятна, нет tooltips.
6. Границы панелей непоследовательны (местами border, местами ничего).
7. Типографика без иерархии: имя/превью/время не образуют сетку.
8. Скроллбар системный толстый (или невидим).
9. 104 setStyleSheet + 105 хардкод-цветов по UI → всё разъехалось.

  hover/pressed/deep/text/soft1/soft2/border, bubble in/out-solid/out-text/meta,

- Глобальный QSS: базовый QWidget, тонкий скроллбар (8px, rounded, полупрозрачный),

- **Verify:** dv ≥269 PASS; скрин main — фон/пузыри/текст из палитры; компилятор
  без новых warning.

### B. Список чатов — TG-плотность (90м)
- Строка чата: высота ~64, аватар 44 круг, имя 15/600 + время 12 tertiary справа,
  превью 13 secondary 1 строка elide, бейдж-цифра pill 18px accent (muted — серый),
  иконки mute/pin tertiary.
- Активная строка: accent-soft-1 фон + белый текст метаданных (TG) или левый
  маркер 3px accent (Discord) — взять оба: фон soft + маркер.
- Hover: surface-3, 120ms; press: surface-4.
- Разделители: border-subtle между списком и чатом, между рейлом и списком.
- Секции «Пины»/папки — заголовки 11/700 uppercase tertiary.
- **Verify:** dv: active-строка фон/маркер, hover-стиль, бейдж pill, эллипсис
  превью, высота строк ±2px стабильна; скрин.

### C. Лента сообщений — TG-сигнатуры (120м)
- Серии: подряд одного автора → gap 2px, между авторами 10px; аватар собеседника
  только под последним серии (место держим visibility), свои — без аватара.
- Пузырь: радиус 14, у последнего серии клюв 4px (скошенный угол); входящие
  surface-2, исходящие bubble-out-solid (#41336A); max-width 70%.
- Время+галочки: внутри пузыря справа-снизу, 11px, out-meta/in-tertiary, «· изм.»
  у отредактированных; клик = меню инфо.
- Дата-капсула: pill surface-3, 12/600 tertiary, паддинги 6/14, sticky не надо.
- Спойлер-фикс: фон #2B2737 → клик раскрывает (точки-паттерн как TG), не чёрный.
- Имена в группах: цвет по hash(userId) из мягкой палитры 6 цветов.
- Ссылки: accent-text + underline, hover accent.
- Реакции-чипы: pill surface-3, своя — accent-border + soft-soft, hover scale.
- **Verify:** dv: серия 3+2 группировка (gap разные), клюв у последнего, время
  в баббле, спойлер-клик, hash-цвет стабилен; скрины x2 (лс+группа).

### D. Композер + эмодзи (75м)
