1. Блок = 1-2 коммита; пуш после каждого; сообщения коммитов — по-русски, как в истории.
2. design-verify только растёт (сейчас 70 PASS).
3. При непонятном — живой прогон (profile-live/call-live/xipher.log), не догадки.
4. Приложение перезапускать после каждого блока.
5. Веб-репо: только разведка чтением; правки — лишь если без них фича десктопа невозможна.
